# Online Resume Builder using Django

## 📌 Project Overview

The Online Resume Builder is a Django web application that allows users to create professional resumes by entering their personal information, education, skills, work experience, and other details through a structured interface.

The project provides a simple and user-friendly way to generate resumes using Django, HTML, CSS, JavaScript, and Bootstrap.

## ✨ Features

- User-friendly resume creation interface
- Personal information management
- Education details
- Work experience
- Skills and other resume information
- Professional resume template
- Responsive web interface
- Django-based backend

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment.
4. Install the required dependencies.
5. Run database migrations.
6. Start the Django development server.

```bash
python manage.py migrate
python manage.py runserver
```

7. Open the application in your browser:

```text
http://127.0.0.1:8000/
```
